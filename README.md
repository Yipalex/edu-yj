# 教培机构业务系统 · 业绩登记系统

多校区教培机构 B 端业务管理后台套件（六系统 + 共用后端）之一。
统一「墨·纸·印」设计语言：纸 #F6F3EC / 墨 #26231F / 印 #B03A2A / 黛 #31565E / 苔 #3E7C4F / 赭 #A9762B，
Noto Serif SC 标题 + MiSans 正文，8pt 网格，768px 响应式断点。

## 套件仓库

| 仓库 | 说明 |
|---|---|
| edu-yj | 业绩登记（课时打卡 / 学费 / 物品销售 / 审核 / 财务） |
| edu-quan | 券类管理（课时券发放、核销与余额流水） |
| edu-jz | 教资报名（内部教师资格认证报名通道） |
| edu-sf | 评测报告（书法评测录入与报告生成） |
| edu-wms | 仓库管理（多校区库存、出入库与盘点） |
| edu-asset | 固定资产（台账、领用借用与调拨） |
| edu-server | 共用后端（认证、数据路由、RBAC） |

## 数据与隐私

- 本仓库**不含任何真实业务数据**；示例数据均为虚构占位。
- 品牌、域名、人名、电话、地址、校区名已全部脱敏。
- 部署前请复制 `.env.example` 为 `.env` 并填写自己的配置。
